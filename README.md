#### JavaScript:

1. Реализована логика работы часов:
   - Создана функция ```updateClock```, которая обновляет время каждую секунду.
   - Время форматируется так, чтобы всегда отображалось двузначными числами (например, ```09:05:07```).
2. Добавлено управление часами:
   - Кнопка ```"Запустить часы"``` запускает таймер с помощью ```setInterval```.
   - Кнопка ```"Остановить часы"``` останавливает таймер с помощью ```clearInterval```.
   - Использован массив ```timerIds``` для хранения ID таймеров, чтобы можно было остановить все запущенные таймеры.
3. Динамическое обновление времени:
   - Время обновляется в реальном времени и отображается в элементе с ```id clock```.
